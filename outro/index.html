Uložit pro vysílání

Změny se uloží do repozitáře anlexcz/studio. Po dokončení publikování obnov zdroj v OBS.

Token zůstává pouze v paměti otevřené stránky. Po jejím zavření ho zadáš znovu.

Jak vytvořit token pro ukládání
  1. Otevři vytvoření fine-grained tokenu v GitHubu.
  2. Resource owner: anlexcz. Repository access: Only select repositories → studio.
  3. Repository permissions: Contents → Read and write. Nastav datum platnosti a token vytvoř.
  4. Vlož ho do pole výše. Neposílej ho do chatu ani do repozitáře.
